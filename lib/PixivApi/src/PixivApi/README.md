# PixivApi

A partial implementation of the [pixivpy](https://github.com/upbit/pixivpy) Python library in C#, used by the Pixiv
parser.

## What's Implemented

- Authentication using refresh token
- Fetching user illustrations
- Fetching ugoira metadata
- Downloading images and ugoira zip files

Tests are in [PixivApi.Tests](../../test/PixivApi.Tests).
